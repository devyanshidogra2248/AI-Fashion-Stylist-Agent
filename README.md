# 👗 AI Fashion Stylist Agent

An AI-powered fashion styling assistant built with **n8n** and **OpenAI** that helps users generate personalized outfit recommendations based on their preferences.

The project explores how **Generative AI + AI Agents + Workflow Automation** can be used to create a practical fashion-tech experience.

---

## ✨ Overview

Choosing an outfit can sometimes be difficult when you have to consider different preferences, occasions, colors, styles, and personal aesthetics.

The **AI Fashion Stylist Agent** acts as a virtual styling assistant. Users provide their fashion preferences through a simple form, and the AI analyzes the information to generate a personalized styling recommendation.

The workflow is designed and automated using **n8n**, with an **OpenAI-powered AI Agent** handling the styling logic.

## ⚙️ How It Works

The current workflow follows a simple pipeline:

**User Input → n8n Workflow → AI Agent → OpenAI → Styling Recommendation**

### 1. User Input

The user provides their fashion preferences through the input form.

### 2. Workflow Processing

The information is passed into an **n8n workflow**.

### 3. AI Stylist

The AI Agent processes the user's requirements and determines an appropriate styling recommendation.

### 4. Generated Recommendation

The OpenAI model generates a natural-language response containing the recommended styling direction.
